# Project Seal | Personal Game Project

> **Status:** Active Early-Stage Personal Project

A 2D top-down isometric RPG project that serves as a practical exploration of core software architecture, state management, and real-time game logic.

---

## Technical Highlights & Features

* **8-Direction Character Controller:** Smooth 8-directional movement mechanics with clamped sprite direction handling and synchronized directional idle states.
* **Animation System:** Integrated multi-directional animation states mapped dynamically to movement vectors and direction clamping.
* **Shaped Inventory System (Prototype):** Early-stage grid and slot-based inventory logic supporting multi-tile item shapes and placement validation.

---

## Development Roadmap

- [x] 8-direction player movement controller
- [x] Sprite direction clamping and idle state handling
- [x] Multi-directional movement animation integration
- [x] Prototype of shaped/grid inventory system
- [ ] Atmospheric lighting and post-processing setup
